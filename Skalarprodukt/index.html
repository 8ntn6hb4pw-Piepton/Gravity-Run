Skalarprodukt als Schatten

Ziehe die Spitzen von a und b. Beobachte, wie der blaue Schatten von a auf die Richtung von b laenger, kuerzer, negativ oder null wird.

Winkel
--
Skalarprodukt
--
Schatten von a in b-Richtung
--
Leitgedanke a . b = |b| * Schattenlaenge
Wenn der Schatten verschwindet, verschwindet auch das Skalarprodukt.

Entdeckungsauftrag

✓
Stelle einen spitzen Winkel ein. Der Schatten zeigt in Richtung b, das Skalarprodukt ist positiv.
✓
Stelle einen stumpfen Winkel ein. Der Schatten zeigt gegen b, das Skalarprodukt ist negativ.
✓
Triff den 90-Grad-Moment. Der Schatten hat Laenge 0 und das Skalarprodukt wird 0.
Erkenntnis: Orthogonale Vektoren haben keinen Anteil in Richtung des jeweils anderen Vektors. Deshalb ist ihr Skalarprodukt 0.
