# Phase-2-Kombinationskatalog zur fachlichen Prüfung

Zweck: Das ist kein fertiger Automatismus, sondern der Prüfkatalog für die spätere Phase-2-Verdichtung.  
Du kannst mit Nummern antworten, z. B. `G012 raus`, `B044 Impuls ändern`, `A006 sehe ich nicht`, `B071 sehr wichtig`.

Grundlogik:

- **2er-Kombinationen**: kleine Gesprächslinien, oft sehr praxistauglich.
- **3er-Kombinationen**: robustere Muster, wenn mehrere Beobachtungen zusammenfallen.
- **4er+-Kombinationen**: große Gesprächszusammenhänge, eher für starke Häufungen.
- **Ambivalent**: grün und blau treten gemeinsam auf; nicht als Widerspruch löschen, sondern als Entwicklungslinie lesen.

Sprachlogik ab Version 2:

- **Grüne Karten** bekommen keine Frage. Sie bekommen eine kurze tragende Rückmeldung: Was war gut erkennbar, und wie hat es das Lernen der SuS gestützt?
- **Blaue Karten** bekommen eine Entwicklungsfrage direkt an die Lehrkraft: `Woran könnten Sie ...`, `Wie könnten Sie ...`, immer mit Blick auf das Lernen der SuS.
- **Ambivalente Karten** bekommen zuerst eine knappe Beobachtungsinfo und dann eine Frage: Was war bereits tragend, und wo könnte die Lehrkraft mit Blick auf die SuS weiterentwickeln?
- Die folgenden Zeilen sind deshalb als fachlicher Kombinationskatalog zu lesen. Die letzte Spalte wird in der nächsten Überarbeitung sprachlich konsequent in `Rückmeldung`, `Entwicklungsfrage` oder `Info + Frage` getrennt.

Spalten:

| Spalte | Bedeutung |
|---|---|
| Nr. | Prüfnummer für deine Rückmeldung |
| Typ | 2er, 3er oder 4er+ |
| Items | Itemkombination |
| Thema | möglicher Kartentitel |
| Kartentext | grün = Rückmeldung, blau = Entwicklungsfrage, ambivalent = Info + Frage |
