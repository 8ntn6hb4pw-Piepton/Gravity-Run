# Phase-2-Musterkatalog zur fachlichen Prüfung

Ziel: Phase 2 soll keinen Wust erzeugen. Intern darf viel gesammelt werden, aber sichtbar werden zuerst kuratierte Gesprächskandidaten.

## Kurationsregeln

| Ebene | Wann entsteht eine Karte? | Sichtbarkeit |
|---|---|---|
| Einzelitem | ein Item wurde mehrfach gleichgerichtet markiert oder einmal sehr stark markiert | wird angezeigt, wenn es nicht von einer stärkeren Zweier-/Dreier-/Musterkarte abgedeckt ist |
| Zweierlinie | zwei Items bilden eine fachlich plausible Gesprächslinie | stärker als Einzelitem |
| Dreierlinie | drei Items zeigen eine robuste didaktische Linie | stärker als Zweierlinie |
| Vierer-/Mehrfachmuster | mehrere Items bilden einen größeren Gesprächszusammenhang | höchste Musterkarte, unterdrückt passende Einzelkarten |
| Ambivalenz | gleiches Item oder gleiche Linie wurde grün und blau markiert | eigener Abschnitt nach grün/blau |
| freie fachliche Beobachtung | passt nicht sauber ins UFB-Spider-Web | eigene freie Karte, nicht ins Spider-Web drücken |

Sortierung in Phase 2: **Lerntragende Wirkungen**, dann **Entwicklungsrelevante Wirkungen**, dann **Ambivalenzen**, dann freie/offene Beobachtungen. Alphabetisch nur als Tie-Breaker, nicht als Hauptlogik.
